Exercise 23 - My containerized prod env
=======================================

The production setup of my own full stack app flightdiaries. The app
repository is linked in the README.md of this exercise repository:
https://github.com/JunubBTC/PART_9 (public).

1. structure

2. my-app/frontend/Dockerfile

FROM node:24 AS build-stage

WORKDIR /usr/src/app

COPY package*.json ./

RUN npm ci

COPY . .

RUN npm run build

FROM nginx:1.29-alpine

COPY --from=build-stage /usr/src/app/dist /usr/share/nginx/html

Multi-stage build: the React/Vite app is built into static files and only
the dist directory is copied into a small nginx image. No dev server, no
source code and no node_modules in the final image.

3. my-app/backend/Dockerfile

FROM node:24

WORKDIR /usr/src/app

COPY package*.json ./

RUN npm ci --omit=dev --legacy-peer-deps

COPY . .

CMD ["node", "--experimental-transform-types", "src/index.ts"]

Only production dependencies are installed. Node runs the TypeScript
backend directly with type stripping (--experimental-transform-types), the
same way the app runs its start script. --legacy-peer-deps is required
because the app's lockfile pins typescript 6 while typescript-eslint
declares typescript <6 as a peer.

4. my-app/nginx.conf

events { }

http {
  server {
    listen 80;

    location /api/ {
      proxy_pass http://backend:3000;
    }

    location / {
      proxy_pass http://frontend:80;
    }
  }
}

The frontend calls the API with the relative url /api/diaries, so all
traffic goes through this nginx: /api/ is proxied to the backend
(preserving the path, the backend serves its routes under /api/) and
everything else to the frontend container, which serves the built static
files on port 80.

5. my-app/docker-compose.yml

services:
  frontend:
    image: flightdiaries-frontend
    build:
      context: ./frontend
      dockerfile: Dockerfile

  backend:
    image: flightdiaries-backend
    build:
      context: ./backend
      dockerfile: Dockerfile

  nginx:
    image: nginx:1.29
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    ports:
      - 8080:80
    depends_on:
      - frontend
      - backend

The images are named flightdiaries-frontend and flightdiaries-backend.
No source code volumes, no dev servers, only nginx publishes a port (8080).
The app has no database, so no other services are needed.
