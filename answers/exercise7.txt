Exercise 7 - Little bit of MongoDB coding (todo-backend)
========================================================

backend kept running on the host (npm start), MongoDB containerized
via docker-compose.dev.yml with the mongo-init.js bind mount and a
named volume for data persistence:

    volumes:
      - ./mongo/mongo-init.js:/docker-entrypoint-initdb.d/mongo-init.js
      - mongo_data:/data/db

volumes:
  mongo_data

fresh initialization:
$ docker compose -f docker-compose.dev.yml down --volumes
$ docker compose -f docker-compose.dev.yml up -d
 Volume todo-backend_mongo_data Created
$ docker volume ls
local     todo-backend_mongo_data

$ npm start                      (node --env-file-if-exists=.env)
$ curl -s http://localhost:3000/todos
[{"_id":"6ad22b2fac282ba54f001ce3","text":"Write code","done":true},{"_id":"6ad22b2fac282ba54f001ce4","text":"Learn about containers","done":false}]

implemented GET /todos/:id and PUT /todos/:id in routes/todos.js
(used to be res.sendStatus(405) placeholders):

  GET -> res.send(req.todo) (todo already loaded by findByIdMiddleware)
  PUT -> Todo.findByIdAndUpdate(req.todo._id,
         { text: req.body.text, done: req.body.done },
         { new: true, runValidators: true })

tests:
