Exercise 21 - E2E tests in CI
=============================

1. the tests

todo-tests/ contains Playwright E2E tests (tests/todo-app.spec.js):

  Todo App E2E Tests
    - frontend loads and displays the todo application
    - can add a new todo via UI
    - can toggle todo completion status
  Backend API Tests
    - GET /api/todos returns todos list
    - POST /api/todos creates a new todo
    - GET /api/statistics returns added_todos count from Redis
    - PUT /api/todos/:id updates a todo

playwright.config.js points baseURL to http://localhost:8080, i.e. the
production environment served by nginx, and only enables chromium.

Playwright is pinned to version 1.59.0 in todo-tests/package.json and the
package-lock.json is committed, so npm ci in CI installs exactly the same
version and the same browser build (chromium revision 1217).

3. the workflow

.github/workflows/e2e-tests.yml triggers on pushes to the main and master
branches:

  on:
    push:
      branches: [ main, master ]

The job runs on ubuntu-latest and:

- builds the production images
  (docker build -t todo-backend ./todo-app/todo-backend,
   docker build -t todo-front ./todo-app/todo-frontend)
- starts the production stack from todo-app/docker-compose.yml
- waits until nginx answers on http://localhost:8080
- runs npm ci and npx playwright install --with-deps chromium in todo-tests
- runs the tests with npm run test:e2e / npx playwright test
- on failure uploads the Playwright report and test-results as artifacts
  and prints the container logs
- always tears the stack down with docker compose down -v
