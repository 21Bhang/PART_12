Exercise 9 - Set up Redis for the project (todo-backend)
========================================================

Redis added to docker-compose.dev.yml after the mongo service
(redis was wired in during the env-file setup, this exercise confirms it):

  redis:
    image: redis
    ports:
      - 6379:6379

REDIS_URL (redis://host:port, default port 6379) comes from .env:
REDIS_URL=redis://localhost:6379

made the server actually use it by requiring the redis module
in routes/index.js:
  const redis = require('../redis')

start mongo + redis, then the backend (npm run dev):
$ docker compose -f docker-compose.dev.yml up -d
 Container todo-backend-mongo-1 Started
 Container todo-backend-redis-1 Started

$ npm run dev
> nodemon --exec "node --env-file-if-exists=.env" ./bin/www
[nodemon] starting `node --env-file-if-exists=.env ./bin/www`
Connected to Redis

$ curl -s http://localhost:3000/
{"MONGO_URL":"mongodb://the_username:the_password@localhost:3456/the_database","REDIS_URL":"redis://localhost:6379","visits":1}

no crash -> configuration is done right ("Connected to Redis" logged)

teardown:
$ docker compose -f docker-compose.dev.yml down --volumes
