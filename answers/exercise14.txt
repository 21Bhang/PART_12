Exercise 14 - Testing during the build process (todo-frontend)
==============================================================

1. extract the Todo component

todo-app/todo-frontend/src/Todos/Todo.jsx now contains everything that renders
a single todo (text, done/not-done info, Delete and Set as done buttons) and
List.jsx only maps todos to <Todo key={todo._id} todo={todo} ... />.

2. test the component

test tools (Vitest + Testing Library, since the app is built with Vite):

$ npm install -D vitest jsdom @testing-library/react @testing-library/jest-dom @testing-library/user-event

vite.config.js gained:

    test: {
      environment: 'jsdom',
      globals: true,
      setupFiles: './testSetup.js',
    }

testSetup.js imports @testing-library/jest-dom/vitest and cleans up after each
test; package.json gained "test": "vitest run".
src/Todos/Todo.test.jsx has 5 tests: renders the text, shows not-done info,
shows done info instead of "Set as done" when done, and both buttons call
deleteTodo / completeTodo with the right todo.

$ npm run test
 Test Files  1 passed (1)
      Tests  5 passed (5)

3. tests in the build process

Dockerfile got a new first stage, and the build stage consumes its output:

FROM node:24 AS test-stage

WORKDIR /usr/src/app

COPY . .

RUN npm ci

RUN npm run test

FROM node:24 AS build-stage

WORKDIR /usr/src/app

COPY --from=test-stage /usr/src/app ./

ENV VITE_BACKEND_URL=http://localhost:3000

RUN npm run build

FROM nginx:1.29-alpine

COPY --from=build-stage /usr/src/app/dist /usr/share/nginx/html

The COPY --from=test-stage is the important part from the "stages that are
not used are skipped" note: a stage that no following stage references is
skipped entirely, so without it the tests would never run during the build.
Copying the tested app (including its node_modules) into the build stage also
means the bundle is built from the code that passed the tests.

failure demo: with a deliberately broken test, the whole build fails:

$ docker build . -t todo-frontend
#12 [test-stage 5/5] RUN npm run test
 Test Files  1 failed (1)
      Tests  1 failed | 5 passed (6)
#12 ERROR: process "/bin/sh -c npm run test" did not complete successfully: exit code: 1

after removing the broken test:

$ docker build . -t todo-frontend
#11 [test-stage 5/5] RUN npm run test
 Tests  5 passed (5)
#13 [build-stage 4/4] RUN npm run build
#15 naming to docker.io/library/todo-frontend:latest

$ docker rm -f todo-frontend
$ docker run -d -p 8080:80 --name todo-frontend todo-frontend
$ curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8080/
200

the dev dependencies stay in the intermediate stages, the final image is still
only nginx + static files (92.9MB).
